# English Translator

급하게 외국인과 말해야 할 때 쓰는 페이지입니다. `index.html` 을 더블클릭하면 열립니다.

## 처음 한 번

1. 열고 오른쪽 위 **⚙️** 를 누릅니다.
2. Claude API 키(`sk-ant-...`)를 넣고 **저장**.
3. 끝. 키는 그 브라우저 안에만 저장되고 밖으로 나가지 않습니다.

폰과 노트북은 각각 따로 넣어야 합니다 (저장 장소가 다릅니다).

## 네 가지 모드

| 모드 | 넣는 것 | 나오는 것 |
|---|---|---|
| 한국어 → 영어 | 하고 싶은 말 | 서로 다른 영어 표현 3개 |
| 영어 → 뜻 | 들은 영어 문장 | 한국어 뜻 + 이어서 할 수 있는 대답 3개 |
| 단어 | 궁금한 단어 | 뜻·쓰임·비슷한 말과의 차이 + 상황별 예문 3개 |
| 내 영어 첨삭 | 내가 쓴 영어 | 뭐가 틀렸는지 + 고친 문장 3개 (최소 수정 / 자연스럽게 / 원어민이라면) |

전부 한국어 설명이 붙습니다.

## 대화 중에 쓰는 법

- **🎤 한국어** 를 누르고 말하면 받아써 줍니다. 타이핑보다 빠릅니다.
- **🔊 듣기** 를 누르면 폰이 영어로 읽어 줍니다 — 상대방에게 들려주세요.
- **영어 문장을 누르면** 화면 가득 크게 나옵니다 — 시끄러운 곳에서 보여주세요.
- **☆ 저장** 은 ⭐ 저장함에 쌓입니다.

## 컴퓨터에 앱으로 설치

**`앱으로 설치.bat` 을 더블클릭**하고, 뜨는 크롬 창에서 주소창 오른쪽 [설치] 를 누르면 됩니다.
루다냥이 앱을 설치하셨던 것과 같은 방법입니다.

설치하면 시작 메뉴와 바탕화면에 아이콘이 생기고, 주소창 없는 자기 창으로 열립니다.
따로 `.exe` 파일을 받는 건 아니지만 윈도우가 앱으로 취급합니다.

## 폰에 앱으로 넣기

https://jiko1212-hub.github.io/english-helper/ 를 폰에서 열고 **홈 화면에 추가** 를 누르면 됩니다.

그러면 아이콘이 생기고, 눌렀을 때 주소창 없이 꽉 찬 화면으로 뜹니다. 구글 번역기와 겉보기가 같습니다.
앱스토어에서 받는 앱은 아니지만 쓰는 느낌은 같습니다.

## 속도

⚙️ 설정에서 셋 중 고릅니다. 답은 다 기다리지 않고 **완성된 것부터 한 줄씩** 화면에 뜹니다.

| | 모델 | 언제 |
|---|---|---|
| ⚡ 빠르게 | Haiku 4.5 | 기본값. 대화 중 급할 때 |
| 🚀 빠르고 좋게 | Opus 5 빠른모드 | 표현이 더 자연스러웠으면 할 때 (요금 2배) |
| 🎯 좋게 | Opus 5 | 앉아서 공부할 때 |

화면 아래에 걸린 시간이 나옵니다 — 예: `연결 0.4초 · 첫 답 1.1초 · 전체 2.3초`

- **연결** 이 길면 → 인터넷 문제 (와이파이, 로밍)
- **연결은 짧은데 첫 답이 길면** → 모델 문제 (속도를 ⚡ 로 바꾸세요)
한 번 찾는 데 몇 원 수준입니다.
