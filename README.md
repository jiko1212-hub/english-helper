# 영어 도우미

급하게 외국인과 말해야 할 때 쓰는 페이지입니다. `index.html` 을 더블클릭하면 열립니다.

## 처음 한 번

1. 열고 오른쪽 위 **⚙️** 를 누릅니다.
2. Claude API 키(`sk-ant-...`)를 넣고 **저장**.
3. 끝. 키는 그 브라우저 안에만 저장되고 밖으로 나가지 않습니다.

폰과 노트북은 각각 따로 넣어야 합니다 (저장 장소가 다릅니다).

## 네 가지 모드

| 모드 | 넣는 것 | 나오는 것 |
|---|---|---|
| 한국어 → 영어 | 하고 싶은 말 | 영어 3개 (격식 / 보통 / 캐주얼) |
| 영어 → 뜻 | 들은 영어 문장 | 한국어 뜻 + 이어서 할 수 있는 대답 3개 |
| 단어 | 궁금한 단어 | 뜻·쓰임·비슷한 말과의 차이 + 예문 3개 |
| 내 영어 첨삭 | 내가 쓴 영어 | 뭐가 틀렸는지 + 고친 문장 3개 |

전부 한국어 설명이 붙습니다.

## 대화 중에 쓰는 법

- **🎤 한국어** 를 누르고 말하면 받아써 줍니다. 타이핑보다 빠릅니다.
- **🔊 듣기** 를 누르면 폰이 영어로 읽어 줍니다 — 상대방에게 들려주세요.
- **영어 문장을 누르면** 화면 가득 크게 나옵니다 — 시끄러운 곳에서 보여주세요.
- **☆ 저장** 은 ⭐ 저장함에 쌓입니다.

## 폰에 넣기

`index.html` 은 노트북 파일이라 폰에서는 그대로 못 씁니다. 둘 중 하나로 하세요.

**(가) 파일을 폰에 옮기기** — 카톡 나에게 보내기 등으로 `index.html` 을 폰에 저장한 뒤 크롬/사파리로 엽니다.
간단하지만 홈 화면 아이콘으로는 못 만듭니다.

**(나) 무료 호스팅에 올리기 (추천)** — [app.netlify.com/drop](https://app.netlify.com/drop) 에 이 폴더를 끌어다 놓으면 주소가 하나 나옵니다.
그 주소를 폰에서 열고 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.
올라가는 건 화면 코드뿐이고 **API 키는 안 올라갑니다** (키는 폰 안에만 저장됩니다).
